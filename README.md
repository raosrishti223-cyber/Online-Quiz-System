# Online Quiz System

## Overview

The Online Quiz System is a web-based application designed to conduct multiple-choice quizzes online. It allows participants to answer questions, submit their responses, and view their scores.

Administrators can manage quiz questions by adding, editing, deleting, and viewing questions.

## Features

* Start and attend online quizzes
* View multiple-choice questions
* Select and submit answers
* Automatically calculate scores
* View quiz results
* Administrator login
* Add, edit, delete, and view quiz questions
* Input validation and error handling
* Basic security and access control

## Technologies

* HTML
* CSS
* JavaScript
* Node.js
* MySQL / MongoDB

## System Requirements

* Windows, Linux, or macOS
* Minimum 4 GB RAM
* Dual-core processor or above
* Modern web browser
* Internet or local network connection

## How It Works

### Quiz Participant

```text
Start Quiz
    ↓
View Questions
    ↓
Select Answers
    ↓
Submit Quiz
    ↓
Calculate Score
    ↓
View Result
```

### Administrator

```text
Login
    ↓
Verify Credentials
    ↓
Manage Questions
    ↓
Add / Edit / Delete / View
```
